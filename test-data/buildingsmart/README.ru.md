# Официальные эталонные архивы buildingSMART

Архивы взяты без изменений из
[buildingSMART/BCF-XML](https://github.com/buildingSMART/BCF-XML), папка
`Test Cases`, коммит `bc48611`. Тот репозиторий под лицензией MIT, как
и этот.

**Зачем они здесь.** Все остальные фикстуры в `test-data/` пишет наш
экспортёр и читает наш же читатель. Непонимание формата, общее для обеих
половин, такую проверку проходит незамеченным: круг замкнут. Эти файлы
сделаны чужими инструментами за годы до появления библиотеки, поэтому
их чтение — единственная внешняя проверка того, понимаем ли мы BCF так же,
как его авторы.

Она нашла своё с первого прогона: в BCF 2.0 компоненты лежат плоским
списком, где выделение и видимость — атрибуты, а читатель знал только
раскладку 2.1. Архивы 2.0 читались как замечания вовсе без компонентов —
целые на вид и бессмысленные.

## Что здесь лежит

| Файл | Ради чего его стоит читать |
|---|---|
| `v2.1/MinimumInformation.bcf` | Самое маленькое законное замечание |
| `v2.1/MaximumInformation.bcf` | Два замечания, три точки зрения, пятнадцать компонентов, чужой справочник, фрагмент, растр |
| `v2.1/ExternalBIMSnippet.bcf` | Фрагмент, лежащий вне архива |
| `v2.1/InternalBIMSnippet.bcf` | Фрагмент, лежащий внутри архива |
| `v2.1/RelatedTopics.bcf` | Два замечания, ссылающиеся друг на друга |
| `v2.0/MinimumInformation.bcfzip` | Минимум версии 2.0 |
| `v2.0/SelectedComponent.bcfzip` | Выделение через плоский список компонентов 2.0 |
| `v2.0/SingleInvisibleWall.bcfzip` | Видимость как атрибут компонента |
| `v2.0/Clippingplane.bcfzip` | Камера и секущие плоскости, записанные чужим инструментом |
| `v2.0/ComponentColoring.bcfzip` | Раскраска, которой наша модель не хранит, — она не должна ломать чтение |

`v2.1/RelatedTopics.bcf` — это файл, который в исходном репозитории
называется `related topics with both topics in the same file/case.bcf`;
изменено только имя, байты те же.

## Чего здесь намеренно нет

**BCF 3.0.** В исходном репозитории эталонных архивов этой версии пока нет.
Значит, наше чтение 3.0 по-прежнему проверяется только против нашего же
писателя — тем самым замкнутым кругом. Когда официальные примеры 3.0
появятся, им место здесь.

**Остальные архивы 2.0 и 2.1.** Полный набор — около пяти мегабайт,
в основном за счёт моделей IFC внутри архивов. Взятые файлы покрывают
конструкции, важные для читателя; остальные повторяют их с более тяжёлым
содержимым.

Ожидания по каждому файлу лежат в
`Bcf.Core.Tests/BuildingSmartTestCaseTests.cs` и сняты с самих архивов,
а не с нашего вывода.
