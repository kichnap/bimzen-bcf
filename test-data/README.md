# Эталонные архивы

Сюда кладутся `.bcfzip`, выгруженные плагином и проверенные по XSD: маленький
набор на 3 топика и большой на 500, каждый в двух версиях (3.0 и 2.1).

Они служат двум целям: фикстуры для тестов `Bcf.Core` и входные данные для
команды онлайн-сервиса, отлаживающей импорт. Файлы генерируются, а не правятся
руками; исключение — фикстуры с намеренно «чужими» значениями статусов,
имитирующие файл из BIMcollab или Revizto.
